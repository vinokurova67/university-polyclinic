# Тестирование

В этой папке будут храниться тесты программных компонентов информационной системы.

Планируемые сценарии проверки:
- регистрация пользователя;
- обработка некорректных регистрационных данных;
- запись на свободное время;
- отказ при попытке записи на занятое время;
- просмотр истории обращений;
- проверка прав доступа пользователей;
- обработка ошибок при сохранении и получении данных.
