# Проекты приложения

В этой папке будут размещаться файлы приложения информационной системы поликлиники.

Система разрабатывается для автоматизации записи пациентов на приём, просмотра истории обращений, работы со справками и расписанием врачей.

Язык программирования, фреймворк и структура приложения будут определены после согласования технологического стека командой.
