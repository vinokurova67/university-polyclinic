# Документация проекта

В этой папке хранится документация информационной системы университетской поликлиники.

## Содержание

- `project-description.md` — описание проекта, его назначения и пользователей.
- `requirements.md` — функциональные требования к системе.
- Диаграммы вариантов использования и последовательностей.
- Другие схемы и проектные документы.

Редактируемые диаграммы рекомендуется хранить в формате `.drawio`, а для просмотра при необходимости добавлять изображения в формате PNG.

Документация обновляется по мере выполнения практических заданий и разработки системы.
