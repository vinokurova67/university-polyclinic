## 1. Вариант использования «Регистрация пользователя»

**Описание:**
Данный вариант использования описывает процесс регистрации пациента в системе поликлиники. В результате выполнения сценария в системе создаётся учётная запись пациента, после чего он получает возможность пользоваться функциями системы.

**Действующие лица:**
- Пациент.

**Предусловия:**
1. Пациент не зарегистрирован в системе.
2. Система доступна для регистрации.

**Основной поток:**
1. Пациент открывает страницу регистрации.
2. Система отображает форму регистрации.
3. Пациент вводит необходимые регистрационные данные.
4. Пациент отправляет форму регистрации.
5. Система проверяет корректность введённых данных.
6. Система проверяет отсутствие ранее созданной учётной записи.
7. Система создаёт учётную запись пациента.
8. Система сообщает пациенту об успешной регистрации.

**Альтернативные потоки:**
- **А1. Введены некорректные данные:**
  1. Система обнаруживает ошибку во введённых данных.
  2. Система не создаёт учётную запись.
  3. Система сообщает пациенту об ошибке.
  4. Пациент исправляет данные.
  5. Пациент повторно отправляет форму.
- **А2. Пользователь уже зарегистрирован:**
  1. Система обнаруживает существующую учётную запись.
  2. Система не создаёт новую учётную запись.
  3. Система сообщает пациенту о наличии учётной записи.

**Постусловия:**
1. Учётная запись пациента создана.
2. Данные пациента сохранены.
3. Пациент может использовать созданную учётную запись для дальнейшей работы с системой.

## 2. Вариант использования «Запись на приём к врачу»

**Описание:**
Данный вариант использования описывает процесс записи пациента на приём к выбранному врачу на определённые дату и время.

**Действующие лица:**
- Пациент.

**Предусловия:**
1. Пациент зарегистрирован в системе.
2. Пациент авторизован.
3. В системе доступно расписание врачей.

**Основной поток:**
1. Пациент открывает раздел записи на приём.
2. Система отображает доступных врачей.
3. Пациент выбирает врача.
4. Система отображает расписание выбранного врача.
5. Пациент выбирает доступные дату и время.
6. Система отображает выбранные параметры записи.
7. Пациент подтверждает запись.
8. Система проверяет доступность выбранного времени.
9. Система создаёт запись пациента.
10. Система отображает сообщение об успешной записи.
11. Система отправляет уведомление о записи.

**Альтернативные потоки:**
- **А1. Выбранное время занято:**
  1. Система обнаруживает, что выбранное время уже занято.
  2. Система не создаёт запись.
  3. Система сообщает пациенту, что время недоступно.
  4. Пациент выбирает другое время.
- **А2. Ошибка сохранения:**
  1. Система не может сохранить запись.
  2. Система не подтверждает запись.
  3. Система сообщает пациенту об ошибке.

**Постусловия:**
1. Запись пациента к врачу создана.
2. Дата и время приёма сохранены.
3. Пациент уведомлён о записи.
