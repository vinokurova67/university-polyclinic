# Функциональные требования

| ID | Требование |
|---|---|
| ФТ-01 | Авторизация пользователей по доступным идентификаторам или через интеграцию с информационной системой вуза. |
| ФТ-02 | Разграничение прав доступа в соответствии с ролью пользователя. |
| ФТ-03 | Запись пациента на приём к врачу на определённые дату и время. |
| ФТ-04 | Просмотр пациентом истории своих обращений в поликлинику. |
| ФТ-05 | Загрузка и выгрузка справок пациентом. |
| ФТ-06 | Просмотр врачом собственного расписания приёма. |
| ФТ-07 | Просмотр врачом списка записанных к нему пациентов. |
| ФТ-08 | Просмотр врачом карты пациента в пределах предоставленных прав доступа. |
| ФТ-09 | Просмотр и контроль записей пациентов администратором. |
| ФТ-10 | Передача предусмотренных сведений пациента в спортивный комплекс университета, если такая передача технически возможна. |
| ФТ-11 | Отправка уведомлений, связанных с записью на приём. |
