# Программные модули

В этой папке будут размещаться отдельные программные модули системы.

Предполагаемые функциональные направления:
- регистрация и авторизация пользователей;
- запись на приём и работа с расписанием;
- просмотр истории обращений;
- работа со справками;
- разграничение прав доступа;
- уведомления;
- административный контроль записей.

Окончательный состав модулей будет определён в ходе разработки.
