## Интерфейс модуля

**Модуль:** appointment-creation (Запись на приём к врачу)

**Связанные требования:**
- ФТ 5.2.1 «Запись на приём»
- ФТ 5.5 «Уведомления о записи»

**Вариант использования:**
- UC-2 «Запись на приём к врачу»

**Назначение:**
Создание записи пациента к выбранному врачу на указанные дату и время,
с проверкой доступности слота и уведомлением пациента.

**Входные данные:**
- patient_id (int) — идентификатор пациента;
- doctor_id (int) — идентификатор врача;
- date (строка, YYYY-MM-DD) — дата приёма;
- time (строка, HH:MM) — время приёма.

**Результат:**
Созданная запись с идентификатором:
{
  "appointment_id": int,
  "patient_id": int,
  "doctor_id": int,
  "date": "YYYY-MM-DD",
  "time": "HH:MM",
  "status": "created"
}
Плюс подтверждение уведомления (ФТ 5.5).

**Ошибочные ситуации:**
- отсутствует patient_id или doctor_id;
- patient_id / doctor_id не int или ≤ 0;
- пустая или некорректная дата (не YYYY-MM-DD, в прошлом);
- пустое или некорректное время (не HH:MM);
- выбранный слот уже занят;
- врач с указанным doctor_id не найден;
- ошибка сохранения записи.
